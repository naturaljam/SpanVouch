# SpanVouch v0.7 Technical Report Design

**Status:** Approved direction B; ready for implementation

**Release target:** v0.7.0 (local only; no tag, GitHub Release, push, or paid call)

**Report title:** IVAD: Evidence-Constrained and Risk-Controlled Failure Diagnosis for AI Agents

**Purpose:** Recast the public IVAD artifact as a Technical Report and add the latest
DeepSeek-only formal analysis without promoting unresolved hypotheses into claims.

## Scope

- Preserve the method-centered title and mathematical protocol framing.
- Replace publication-status language (`paper`, `preprint`, `论文`, `预印本`) with
  `technical report` / `技术报告` only in publication-facing material; leave software
  documentation and ordinary engineering terms unchanged.
- Update the report abstract, introduction, evaluation design, results, limitations,
  conclusion, and claim-evidence map with the checked formal analysis.
- Publish a minimal aggregate evidence bundle under the version-controlled `evals/reports/reference/`
  tree. It contains no credentials, raw provider payloads, or per-request result files.
- Bind the bundle to the evaluated-results SHA-256
  `bc09f1b134de9370a3b5209fa5e959bce01abbcdf05c8456af1f069fc4cd3088`, the analysis-input
  manifest hash, and per-file hashes from the source analysis manifest.
- Refresh stale engineering snapshot numbers only from fresh local or v0.6 CI evidence;
  do not invent test or coverage values.
- Extend delivery/document assertions first, then implement documentation and evidence
  changes without adding provider, network, paid-call, or runtime dependencies.

## Scientific boundary

Formal results are observational and DeepSeek-only. B0--B3 completed; B4 and B5 are
`policy-skipped` with no Qwen results. Report the observed B3-vs-B2 risk/coverage tradeoff
and OpsLab replication interval, while keeping H1--H5 `unresolved`. Do not claim support,
cross-model generalization, causality, independence, or an empirical target-risk certificate.

## Non-goals

- No new experiment execution, provider access, Qwen run, or network lookup.
- No changes to IVAD mathematics, thresholds, policy, or experiment configs.
- No renaming of the PDF/source tree or software-only uses of “paper” such as paper asset APIs.
- No release tag, remote publication, or paid provider invocation.
